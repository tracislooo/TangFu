# FM27 跨 Agent / AI 迁移交接包

整理日期：2026-11-03（用户时区 America/Denver）。本包用于接手知识、规则与代码，不是游戏安装包。

## 怎么用

1. 只给 AI 一份材料：上传 `01-完整交接材料.md`。
2. 让支持本地文件的 Agent 接手：解压整个交接包，先读 `01-完整交接材料.md`、`02-接手提示词.txt`，再按模块读 `参考资料`。
3. 真正迁移到另一台电脑：还需转移原工作区、独立皮肤工程及所需图片/字体/游戏资源。材料包没有这些二进制资产；清单与校验见 `资产与环境清单.json`、`工作区文件索引.csv`。

## 内容

- `01-完整交接材料.md`：最终规则、全部19个置顶聊天模块、状态冲突与工作流程。
- `02-接手提示词.txt`：可直接复制到其他 Agent / AI 的说明。
- `参考资料/`：现有 Markdown 维护说明、当前状态JSON、禁用ID清单及根目录Python脚本。原文保留，可能含被撤销方案；以交接材料的冲突说明为准。
- `记录/`：工作区现存 manifest、transaction、README、安装状态文字等小型记录；只供追溯，不能据此批量恢复历史包。
- `证据/`：19个置顶聊天索引及每个聊天最多最近8轮的用户文字、最终答复。不是完整聊天备份，不含附件图片、工具输出、内部推理。
- `文件校验清单.json`：本交接包文件的 SHA256；`校验交接包.py` 可验证解压后的文件。

## 边界

本次仅创建交接资料、复制文本/源码和读取文件校验；未改游戏、皮肤、注册表、原索引或原AGENTS.md，未启动游戏或控制桌面/浏览器。聊天里的临时截图路径不保证仍存在，截图像素没有包含。

脚本为历史源码副本，很多脚本导入时就会写文件。接手者不得批量执行，也不能通过 import 来“查看功能”。先静态阅读，再适配路径、基线、数据格式和最新要求。

这是一份时间点快照。以后收到用户新要求或原工作区有新改动，重新核对实际文件和哈希；不要将本包当作永久最新状态。

最初保存配置时没有修改游戏。后续接入修改仅涉及当前游戏的管理模块资源和单项书签偏好，保留存档、原皮肤工程及认可归档。`build-preset.py` 仍只导出源 JSON，重新运行会生成未接入状态；实际安装状态以 `../current-sidebar-version.json` 为准。

# 比赛界面头像与布局调整

此补丁读取当前已安装资源后生成，包含备份、修改后的模板、资源包及一键恢复脚本。

红框不是一个独立的 Highlight 文件，它是比赛概览内容网格。

| 部位 | 当前资源模板 | 资源包 |
|---|---|---|
| 内容入口、管理比赛与旁观比赛的网格选择 | `OverviewPrototype`，PathID `6781033998951449617` | `ui-visualtreeassets_assets_matchvisualtreeassetpreload.bundle` |
| 模块的网格组合、不同尺寸布局入口 | `MatchExperienceHumanGridCompositionSet`，PathID `-318005293625623753` | `ui-tileslayouts_assets_all.bundle` |
| 两侧阵型面板及阵型/统计切换 | `TeamFormationAdaptiveBlock` | `ui-visualtreeassets_assets_globalvisualtreeassetpreload.bundle` |
| 两侧阵型中的头像、姓名、角色、评分及体能圆环 | `TacticsMatchPositionFilled`，PathID `2040735658139592085` | `ui-visualtreeassets_assets_globalvisualtreeassetpreload.bundle` |

入口和网格组合保留原状。本次修改两侧球员的展示模板，中间实时二维球场保留原状。

## 其他修改位置

| 功能 | 模板 |
|---|---|
| 赛前名单首发、替补头像 | `HomePlayersListRow`、`AwayPlayersListRow`、`HomeSubPlayersListRow`、`AwaySubPlayersListRow` |
| 裁判头像 | `TeamNewsPanel_DisplayingMatchSquad` |
| 球队训话的姓名前头像 | 专用 `MatchTeamTalkPortraitNameCell`；由 `TeamTalkPlayerReactionTableFactory` 的 name 列引用 |
| 通道采访主教练头像 | 专用 `MatchTunnelManagerSender`，100×100，与记者标准头像一致；经 `MatchTunnelSpeakToContainer`、`MatchTunnelMeetingTemplate` 接入 `TunnelInterviewPanel` |
| 记分牌左移 | `OverviewHeader` 的 `SIVisible_MatchStatePeriod_ABSOLUTE` |
| 战术栏移到底部右侧 | `SquadOverview` 的 `MatchBottomTacticalToolbar`，放在球员条的展开/收起开关之前；随底部内容流式布局 |
| 菜单向上打开 | `MatchUITacticalOptions` 中原生下拉及浮动弹窗设置 TopRight（5） |
| 底部球员卡片 | `SquadOverviewPlayerBlock`、`SquadOverviewPlayerBlockSmall` |

底部卡片从上到下为：原位置／原生完整角色职责描述／头像（左侧体能圆环及下方百分比）／姓名／状态、评分、表情。角色文字沿用原生 `Tactic.PositionFromTeamSelectionIndex` 和 tactical_role 翻译，不编造无数据的职责名称。替补尚未有战术位置时角色描述可能为空。

体能直接绑定 `playerinfo.Condition` 与 `position.MatchPlayer.Condition`，UI 值 0～100 对应 0%～100%，缺失显示 `--`。头像复用原生 `PersonPicture`，沿用游戏已有照片与默认头像逻辑。

## 文件位置

- 本目录 `templates/` 是从本次补丁导出的当前模板，适合检查结构；直接编辑 JSON 不会自动生效，需要重新打包。
- 游戏资源目录：`F:/Steam/steamapps/common/Project Taco/fm_Data/StreamingAssets/aa/StandaloneWindows64`。
- 皮肤同步目录：`G:/Doc/FM Skin Builder/skins/tf27-01/packages`。
- `backup-game/`、`backup-skin/` 保存修改前文件；`manifest.json` 记录变更对象及校验值。
- 重新安装：关闭游戏后运行 `install.ps1`。
- 恢复原状：关闭游戏后运行 `restore.ps1`。恢复会还原原文件，并移除本次新增的比赛布局包。

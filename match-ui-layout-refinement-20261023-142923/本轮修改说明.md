# 本轮比赛布局修正

## 已修改

1. 主队首发及替补的头像移动到号码右侧，与客队排列形成镜像；清除头像额外的上下间距。
2. Highlight 阵型节点保持原来的 32px 头像区域，头像先绘制，评分与位置后绘制，避免头像覆盖文字。
3. 战术指令栏改为绝对定位，高度 32px，不参与底部高度计算；在展开、收起及两种宽度版本中直接锚定替补模块上方，右侧与替补区右边缘一致。移除了上一版额外的顶部间距。
4. 底部球员卡恢复原 152px 总高度：位置标题 32px，内容 120px。体能圆环与百分比移动到原体能图标所在的评分行，隐藏旧体能图标并保留伤病分支；角色文字放在评分下方。

角色绑定补齐原生查询需要的 `playerinfo.PlayerTeamSelectionIndex` 与 `inpossession=True`；角色数据取自比赛战术的 `tactic.IPRole`，沿用原生完整角色翻译。角色尚未分配的替补不会虚构角色名称。

## 主要控制模板

- 主队头像顺序：`HomePlayersListRow`、`HomeSubPlayersListRow`。
- Highlight 球员头像与评分层次：`TacticsMatchPositionFilled`。
- 战术栏及替补锚点：`SquadOverview` 中的 `MatchSubstitutesAnchor_*`、`MatchBottomTacticalToolbar*`。
- 底部球员布局：`SquadOverviewPlayerBlock`、`SquadOverviewPlayerBlockSmall`。
- Highlight 内容与底部的高度分配：`OverviewPrototype`。

当前模板导出在 `templates/`；实际游戏读取打包后的 bundle，编辑 JSON 不会直接生效。

## 验证和备份

资源结构及序列化回读通过；375 个体能输入场景通过；检查了四种展开/宽度分支的替补锚定关系、角色查询参数、旧图标隐藏和伤病分支保留。未改动目录索引或其他资源对象，详见 `verification.json` 和 `manifest.json`。

本轮尚未在游戏内进行视觉验收，因此记录 `runtime_verified=false`。

修改已同步到游戏与 `tf27-01` 皮肤包。`backup-game/`、`backup-skin/` 保存本轮修改前的文件。关闭游戏后运行 `restore.ps1` 可回到本轮修改前；运行 `install.ps1` 可重新安装。安装和恢复都会先校验文件，避免覆盖后续改动。

按用户要求，在安装与校验完成后安排正常关机，不强制关闭有未保存内容的程序。

# FM27 启动页：球场覆盖层与横幅动图维护说明

整理日期：2026-10-28（America/Denver）。范围为本聊天的启动页修改，以及底部“视频指南”横幅的实现调查。

## 1. 最终要求与已实施内容

在 Start screen 的电脑版 `MainMenu` 新增 `KunshanStadiumModelOverlay` 图片层，直接引用现有 `kunshan stadium` 纹理。

最终从底向上的显示顺序：

```text
原生人物模型／3D 场景
→ kunshan stadium 全屏图片
→ 原生启动页菜单、按钮及其他前景控件
```

- 图片采用绝对定位，left / right / top / bottom 均为 0，随页面铺满。
- 缩放为 `scale-and-crop`：保持比例，按视口裁切铺满。
- opacity 为 1，`pickingMode = Ignore`，不获取焦点，不拦截菜单点击。
- 新元素插入 MainMenu 的 BindingRoot 子节点列表首位，让原菜单继续绘制在图片上方。
- 原菜单的节点、样式、数据绑定、点击事件和显示条件保留。
- 使用现有背景纹理，不重复导入图片、不新增纹理 ID；本次只修改 MainMenu 类型树及其 inlineStyle，并增加指向 backgrounds 的外部文件引用。
- 底部视频指南横幅保留原生行为。球场覆盖图目前为静态图片；本聊天未实施动态球场背景。

1. 退出游戏，备份更新后的原生 intro、backgrounds、相关 UI 包及游戏／皮肤 catalog。
2. 读取当前 `AGENTS.md`、`reserved-texture-ids.json`、`current-custom-textures.json`。确认 `kunshan stadium` 在最新有效 backgrounds 中存在，名称、固定 ID 与纹理内容正确。
3. 若更新重置了 backgrounds，以更新后的原生包为基础，仅迁移当前有效清单中的自定义纹理；保留新版原生资源。旧 V61 背景包只供历史定位和回退。
4. 在更新后的 intro 包中找到电脑版 MainMenu 及实际 inlineStyle。按第 1 节重建一个普通 VisualElement 覆盖层，插在 BindingRoot 原有子节点之前。使用新版类型树／序列化结构。
5. 在 intro 包 externals 中解析或添加最新 backgrounds 的 CAB 引用；覆盖层 background-image PPtr 指向该外部文件中的 `kunshan stadium`。
6. 校验 MainMenu 的实际 GUID 已登记在新版 catalog，类型为 VisualTreeAsset、对应包确实含该对象、目录依赖首项为 intro，并包含 backgrounds。需要补依赖时分别处理游戏和皮肤 catalog，保留各自已有登记，并按当前目录方式更新 catalog.hash。
7. 同时核对已有自定义 VisualTreeAsset／VisualFunction 的 GUID、类型、实际对象、所属 bundle 首项和背景依赖，避免恢复启动页时破坏卡面及评分函数加载。
8. 打包回读：验证节点唯一性、父子关系、样式索引、图片 PPtr 解引用及真实纹理字节；确认其他原生对象和原菜单绑定未改变。

## 5. 底部“视频指南”横幅：已调查机制

这是游戏原生视频播放链路，本聊天只读取并调查资源，未修改横幅。

```text
按语言选择 PromoBanner_*.webm 视频
→ PromoBannerPlayer 上的 Unity VideoPlayer
→ PromoBannerRenderTexture
→ MarketingBannerTile_8x2 内的 SIImage
```

| 项目 | 已确认值 |
|---|---|
| 资源包 | `promobanner_assets_all.bundle` |
| 中文视频 | `PromoBanner_SCH`，原始导入路径以 `PromoBanner_SCH.webm` 结尾 |
| 视频规格 | 640 × 112，30 fps，450 帧，约 15 秒，无音轨 |
| 播放器对象 | `PromoBannerPlayer` |
| 播放配置 | `m_PlayOnAwake=true`、`m_Looping=true`、`m_PlaybackSpeed=1` |
| 渲染纹理 | `PromoBannerRenderTexture`，640 × 112 |
| 渲染纹理 GUID | `073b324505f39d44796109e923324e46` |
| 渲染纹理 Path ID | `5123726807077961870` |
| 界面模板 | intro 包内 `MarketingBannerTile_8x2` |
| 图片节点 | `banner` 与 `SimpleBanner` 均引用同一 RenderTexture |
| 点击 | 单独绑定 `promo.PromoURL` |

控制组件包含按语言选择视频的 `m_defaultBanners`，并引用同一输出渲染纹理。视频播放器的 `m_TargetTexture` 指向上述 RenderTexture；界面 SIImage 的 `RenderTexture` 字段引用该纹理 GUID。

样式类名虽然带 `8fps`，当前包内视频元数据实际为 30 fps。

后续如用户要求动态球场背景，可以基于此播放链路另行实现；需要同时处理视频、播放器、输出纹理、界面引用和 Addressables 依赖，本次未作此项修改。

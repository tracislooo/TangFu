# TacticsPositionCombined 层叠卡片首版试装

已安装到游戏与 tf27-01 皮肤。游戏内视觉与交互尚待验证。

- 仅修改 Combined 模板和其内联 StyleSheet，共两个已有对象；Detailed、右表、图片包、catalog 均不变。
- 卡片 80×86px，原球场锚点范围 80×70px；卡片在锚点上方延伸。原生位置颜色底层，头像内缩 3px，圆角 8px。
- 体能位于左上，数字 10px；原 IP/OOP 职责移动图标在其下竖排，保留原显隐逻辑；伤停、事件与黄牌提示保留于右上。
- 底部使用原生两组职责按钮，保留绑定、事件和提示；下方为 80×4px 的体能条，再下方为姓名与原生星级。
- 体能直接读取 position.Player.Condition 的 0–100，复用原百分比判断树；缺失显示 -- 和灰色轨道。
- 原生位置色调用 ColourOnly 列，将样式应用到色底自身，未硬编码位置颜色。
- 校验包括 114 个体能输入、所有原序列化绑定不变、其他世界包对象字节不变、受保护包和目录哈希不变。

退出游戏后运行 restore.ps1 可恢复试装之前的游戏包与皮肤包（backup-original）。

# 战术位置六组新颜色

已安装游戏与 tf27-01 皮肤；实际游戏显示待查看。

前锋 #E53935 红；前腰 #FB8C00 橙；中场 #FFD700 金；后腰 #2196F3 蓝；后卫 #43A047 绿；门将 #9C27B0 紫。

修改原生位置 foreground 变量，使用此配色的位置标识一起更新。两种卡片布局、体能渐变、左右脚色块、报告悬停、表格、图片和目录未修改。

分别保留游戏与皮肤已有 default 包，皮肤之前缺失的 common 从当前游戏原生包派生补入。每份样式仅改六个变量引用，旧颜色池与其他对象保留。成品24个颜色定义和保护文件哈希已核验。

退出游戏后运行 restore.ps1 恢复原配色；脚本会同时移除本次新添加的皮肤 common 包。

源码 recolor-tactics-position-palette-v5.py；新版游戏应迁移六个变量，不整包覆盖旧资源。

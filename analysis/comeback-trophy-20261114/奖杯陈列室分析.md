# Comeback Skin v1.8.3 奖杯陈列室分析

本报告直接读取用户提供的九份 bundle。没有修改源皮肤或当前游戏，没有启动游戏或操作浏览器。以下是静态资源分析，不代表已验证游戏内效果。

## 实现方式

用原生俱乐部历史荣誉数据生成卡片，在 Unity UI Toolkit 中叠加柜体背景、灯光、阴影、奖杯图、铭牌文字。没有发现这套陈列柜使用 3D 场景或奖杯模型；这里的具体柜体节点是 VisualElement 和 SIImage。

调用链：ClubHistoryHonoursCardGridComposition → ClubHistoryHonoursBlock → WrappedObjectList → ClubHistoryHonourCardRow。

## 页面和数据

- ClubHistoryHonoursBlock：Path ID -8436403980044243281，GUID 6c64bbef698f0ef41abfed580c7fdf18。
- ClubHistoryHonourCardRow：Path ID -5495443699739417454，GUID 31ffa54435a873f41ac1574b92fc89a8。
- 两者在 gameworldvisualtreeassetpreload 包中，包内容器键可以解析到相应 VTA。
- WrappedObjectList 读取 teamcontainer.HistoryHonours.HistoryHonoursList，每条记录传入 row。
- 新卡片 FMETCabItem 与保留的原荣誉列表 Content 并存，USS 在 fmet-cab 范围内隐藏 fmet-cab-orig，显示 fmet-cab-item。因此主要是替换展示方式，继续使用游戏数据。
- FMETCabWon 使用比较函数 d52cf0b2ba55c764b9ecda52092aa257，比较操作值4，阈值0，输入 row.Winners.Count；FMETCabSeveral 使用同一操作，阈值1。按现有比较约定，分别是夺冠数大于0显示卡片、大于1显示次数。
- 名称绑定 row.Competition.Name；次数绑定 row.Winners.Count，乘号是独立文本“×”。每个赛事荣誉记录一张卡，不按夺冠次数复制奖杯。
- 实际新增的柜体卡片没有挂接夺冠年份文字；样式表虽保留 fmet-cab-years 规则，不能据此推断页面展示了年份。

## 奖杯图片

- FMETCabTrophy 和 FMETCabLogo 都使用 SIImage，调用同一个图形查询函数 7a35874b5cb0acb4d846df3f46c3a872。
- 输入包括 row.Competition.ObjectLookupData、PrimaryColor、SecondaryColor、TertiaryColor。
- 两个控件的 GraphicsUtils.ResourceType 实参分别为11和1，分别用于奖杯图和赛事标识的两个资源请求。请求本身由游戏图形系统处理，奖杯图片没有逐项硬编码在这套 UI 里。
- TrophySlot 另外按 row.Competition.UniqueId 与7作比较；Logo 是相邻的另一节点，外层容器 overflow:hidden。不能仅凭节点名把它描述成“加载失败自动切换”的逻辑。
- 缺图具体表现、外部奖杯图片包覆盖范围，需要实际图形资源或游戏内验证；用户提供的九份文件不足以确认全部赛事的图片是否齐全。

## 排列和尺寸

AlwaysAppliedStyleSheet 位于 ui-styles_assets_default.bundle，主要规则为 fmet-cab-*（规则索引6024–6053）。

- fmet-cab-scroll：外层 SIScrollView；横向滚动条隐藏，纵向按需。
- fmet-cab-shelves：flex-direction:row，flex-wrap:wrap，justify-content:center。
- 卡片250×340px，不收缩。
- 层板背景宽100%、高340px，纵向 repeat，横向 no-repeat，所以换行后继续对应下一层板。
- 灯光270×300px，左-10、上0。
- 阴影150×24px，左50、上248。
- 奖杯区域200×200px，左25、上64，隐藏溢出。
- 铭牌226×32px，左12、上282，使用背景切片；赛事名和次数13px加粗。
- 主页面网格配置为12×8，荣誉块占满；description还保留8×4配置。网格单位不是屏幕像素。

## 迁移所需部分

主要是 gameworld 包内两份VTA、相关内联样式，以及 default样式包的 fmet-cab-* 规则和上述四张纹理。页面入口与网格由 panelids/tileslayouts 等资源衔接；若复用既有荣誉页，应以目标版本当前资源为基础增量调整，不能直接整包覆盖。也须核对目标 catalog 的VTA和函数登记，以及贴图引用的文件号/Path ID。

本次没有迁移或安装。原始对象JSON、完整索引及精简节点/样式分析保存在 objects、index.json、compact.txt。

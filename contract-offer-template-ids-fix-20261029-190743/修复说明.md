# 提供合同页面空白修复

已安装到 Football Manager 27 游戏目录和 tf27-01 皮肤目录。

原因：更新后的 ContractNegotiationTool 页面包含 66 处模板覆盖，使用新版控件 ID；迁移后的 ContractNegotiationToolTemplate 仍保留旧版控件 ID，导致全部覆盖无法找到对应控件，数据绑定无法应用。

修改：仅修改该模板的 77 个 m_Id/uxmlAssetId 字段，并递增内容哈希。使用本次游戏更新时备份的新版原生模板作为 ID 对照；保留现有样式、自定义子模板、名称、Path ID、GUID 和所有其他对象。

检查结果：66/66 覆盖的完整路径（含嵌套模板）均可解析；重新读取打包结果，修改对象与预期一致，其他对象原始字节一致。游戏和皮肤的所有其他 bundle、catalog 和图片清单哈希均未变化。安装后核对两处文件与成品完全一致。

按用户要求，未启动游戏、未控制桌面，未进行游戏内视觉验证。

manifest.json 为详细记录；restore.ps1 可在游戏退出且资源未被后续修改时恢复本次修改前的两个文件。
